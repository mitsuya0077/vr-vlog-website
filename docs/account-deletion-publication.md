# アカウント説明と削除案内の公開前確認

この変更は任意アカウント機能に合わせた情報取扱いと削除窓口の案内。
サイトへの公開と、アカウント機能の本番提供は別々に確認する。
既存の配備workflow、分析同意、他の機能の説明は変更しない。

- プライバシー本文はアプリ側の承認済み正本と同一のJSONを使う。
  既存の利用規約本文とその改定日を維持し、プライバシー固有の改定日だけを更新する。
- 任意のApple／Googleログインと、本人が設定した名前・縮小アイコンの同期を説明する。
  認証サービスに残る連携先情報を「保存しない」「運営が閲覧できない」と案内しない。
- `/privacy/#account-deletion`から既存メール窓口へ削除を依頼する。
  メール作成用リンクは宛先・件名だけを設定し、認証情報や個人値を付加しない。
  このサイトにログイン、情報入力フォーム、新しいデータベースは追加しない。
- これは削除の依頼窓口で、自動退会の完了画面ではない。
  受付担当・本人確認・関連プロフィールと認証アカウントの削除・Apple失効・
  必要最小限の削除済み記録の整理を、対応版の本番提供前に確認する。
- アプリや保存済み連絡先を使えない場合の本人確認を確定する。
  表示名だけの一致で削除せず、パスワードや認証コードの送信も求めない。
  未確認のケースがある間は、全ケースを処理できるとは案内しない。

ローカルの型検査・静的ビルド・画面確認は、公開済み本文との一致や
メール送信・受付・本人確認・削除の運用実績を証明するものではない。
