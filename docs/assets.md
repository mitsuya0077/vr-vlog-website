# Site assets

The photos in `public/images/` come from the site owner's approved website mockup.
Avatar pixels and the app interface use the owner's supplied screenshots. Scene
backgrounds were prepared with the owner's approval. The WebP files are lossless
encodings of those approved images; decoded pixels were verified against the sources.
Do not regenerate or redraw the avatars when changing the site.
